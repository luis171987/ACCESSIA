## Criterios para mantener este archivo

- Cada versión se asocia a su tag y commit exactos; su README enlaza los instaladores reales por plataforma y los archivos fuente/documentos de esa revisión.
- Los binarios grandes se distribuyen en Releases; los ZIP de código fuente se identifican como código, no como instaladores.
- Las imágenes se organizan bajo `YYYY-MM-DD_vVERSION/imagenes/`, por plataforma o tipo, con nombres correlativos. Las sesiones adicionales se conservan en subcarpetas de fecha/hora. Se mantienen las URLs y recursos anteriores.
- Las capturas muestran una aplicación realmente ejecutada y una versión identificada. Se registran fecha, plataforma y procedencia; se usan datos de prueba sin información personal. Las ilustraciones y los logotipos se etiquetan por separado.
- Una beta o un artefacto CI conserva su condición experimental. La existencia de un instalador y de imágenes no sustituye las pruebas de aceptación de la entrega.
- El README principal destaca la versión completa verificada disponible y permite consultar las anteriores. Si falta un instalador, una validación o una captura real, se registra el pendiente en lugar de inventarlo.
- El manifiesto `archivos.json` enumera todos los archivos del árbol de la versión cuando la consulta de Git es completa. Un identificador de blob Git no se presenta como SHA-256 de un instalador.

**Validación física pendiente:** no se realizan instalaciones, desinstalaciones ni capturas en un dispositivo físico sin autorización expresa de su responsable. Las capturas reales de Android y Windows de esta beta permanecen pendientes.
